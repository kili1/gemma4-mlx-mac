# Roadmap

## V1

- MLX-LM text generation behind `/v1/chat/completions`.
- Streaming chat in the frontend.
- Model download and cache status.
- Text LoRA/QLoRA execution with adapter registry.
- Adapter activation and evaluation.

## V2

- Gemma 4 multimodal chat through MLX-VLM.
- Image/audio dataset preparation for multimodal tuning.
- Prompt caching and long-context workflows.
- MTP drafter support for supported Gemma 4 model pairs.
- Signed macOS app wrapper if the Python install path is stable.
